# GoCars — Car Mobility & Rental Platform

GoCars is a full-featured car mobility and rental platform supporting self-drive car rentals, car-with-driver services, fleet management, dynamic pricing, and automated booking workflows.

---

## Project Structure

```
go_cars/
├── backend/                  # FastAPI + SQLAlchemy 2.0 + PostgreSQL Backend
│   ├── app/                  # Application code (Clean Layered Architecture)
│   ├── alembic/              # Database migrations
│   ├── tests/                # Automated pytest suite
│   ├── requirements.txt      # Python dependencies
│   └── README.md             # Backend setup & API documentation
└── frontend/                 # React frontend (Planned for future phase)
```
